What ☁ Sync does: Saves your notes, book concepts, outlines, synopses, and custom books to a Google Sheet you own. Any device with ProfitScout can Push data up or Pull it down to stay in sync across devices.
① Create & share a Google Sheet
1. Open sheets.google.com and sign in
2. Click the large + button (top left, labelled Blank) to create a new sheet
3. Click the title (Untitled spreadsheet) and rename it ProfitScout Data
4. Click Share (top right, blue button)
5. Under General access click the dropdown that says Restricted and change it to Anyone with the link
6. Change the role on the right from Viewer to Editor
7. Click Done
8. Now look at the URL bar — copy the long ID between /d/ and /edit:
   docs.google.com/spreadsheets/d/THIS-PART-HERE/edit
② Get a free Google API Key
1. Go to console.cloud.google.com
2. Click Select a project at top → New Project → name it anything → Create
3. Left menu: APIs & Services → Library → search Google Sheets API → Enable
4. Left menu: APIs & Services → Credentials → + Create Credentials → API Key
5. Copy the key (starts with AIza…) — done, no other setup needed
